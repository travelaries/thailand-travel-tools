
# Thailand Travel Budget Calculator 🇹🇭

A free, mobile-friendly Thailand holiday budget calculator created by **[Travelaries](https://travelaries.com/)**.

Plan your Thailand trip by estimating accommodation, food, local transport, activities, flights and other expenses in Thai baht (THB) and South African rand (ZAR).

## 🌴 Try the Calculator

**[Open the Free Thailand Budget Calculator](https://travelaries.github.io/thailand-travel-tools/)**

## ✨ Features

- Estimate travel expenses for individuals and groups
- Calculate accommodation costs using hotel nights and rooms
- Plan daily food, transport and activity budgets
- Add flights, insurance, visas and miscellaneous expenses
- Include a contingency allowance
- Convert estimated THB expenses into ZAR using an editable exchange rate
- View total group costs and estimated costs per traveller
- Mobile-friendly design

## 🧮 How to Use

1. Enter the number of travel days, hotel nights and travellers.
2. Enter estimated daily expenses in Thai baht.
3. Add optional one-time expenses.
4. Enter a current THB-to-ZAR exchange rate.
5. Click **Calculate My Budget** to see your estimated trip cost.

**Note:** Exchange rates are entered manually. Results are planning estimates, not live travel prices or booking quotes.
